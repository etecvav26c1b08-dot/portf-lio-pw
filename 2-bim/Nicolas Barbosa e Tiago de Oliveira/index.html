O QUE É CSS

CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a apresentação visual de
documentos HTML, como cores, layouts, fontes e espaçamentos. Enquanto o HTML estrutura o conteúdo, o CSS o torna visualmente
atraente e responsivo. Ele permite separar a estrutura do design, facilitando a manutenção e atualização de sites.

SELETORES

Seletores CSS são padrões usados para selecionar e estilizar elementos HTML, fundamentais para definir a
aparência de uma página web. Eles incluem seletores básicos (tag, classe, ID, universal)
e avançados (descendentes, filhos, irmãos, atributos), permitindo controle preciso da Cascata CSS.

PROPRIEDADES

Propriedades CSS são pares de chave-valor usados para estilizar elementos HTML, definindo características como cor,
tamanho, fonte e layout. Elas compõem as regras CSS (junto com seletores) para alterar a aparência da página. As principais
propriedades cobrem texto, fundo, espaçamento (margin/padding), bordas e posicionamento (flexbox/grid).

VALORES

Os valores CSS definem como as propriedades de estilo são aplicadas, incluindo
unidades de medida (px, em, %, rem), cores (hex, rgb, hsl), palavras-chave (auto, none, bold) e funções
(url, calc). Eles podem ser absolutos, como pixels, ou relativos, essenciais para layouts responsivos.
